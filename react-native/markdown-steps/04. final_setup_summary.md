## 🚀 How to Build APK

### Using Podman (Recommended for your setup)
```bash
# On Windows
build-podman.bat

# On Linux/Mac
chmod +x build-podman.sh
./build-podman.sh
```

### Manual Commands
```bash
# Create output directory
mkdir output

# Build container
podman build -t local-ai-assistant .

# Build APK
podman run --rm -v "$(pwd)/output:/host-output:Z" local-ai-assistant
```

## 📱 Installation Process

1. **Build APK**: Run the build script
2. **Enable Developer Mode**: On Android device
3. **Enable USB Debugging**: In Developer Options
4. **Install APK**: `adb install output/local-ai-assistant.apk`
