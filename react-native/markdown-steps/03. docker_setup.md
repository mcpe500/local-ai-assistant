# Docker/Podman Setup for Local AI Assistant

## Overview
This document outlines the containerized build process for creating an Android APK of the Local AI Assistant using Podman (or Docker).

## Prerequisites
- Podman installed on your system
- At least 8GB of free disk space
- Internet connection for downloading dependencies

## Build Process

### Using Podman (Recommended)
```bash
# Make the script executable
chmod +x build-podman.sh

# Run the build
./build-podman.sh
```

### Manual Podman Commands
```bash
# Create output directory
mkdir -p output

# Build the container image
podman build -t local-ai-assistant .

# Run the build process
podman run --rm -v "$(pwd)/output:/host-output:Z" local-ai-assistant
```

## Container Configuration

### Base Image
- **Ubuntu 22.04**: Stable base with good Android development support

### Installed Components
- **Java 17**: Required for Android development
- **Node.js 18**: React Native requirement
- **Android SDK**: Platform tools, build tools, and NDK
- **Python 3**: Build dependencies

### Build Process Inside Container
1. Install system dependencies
2. Set up Android SDK and accept licenses
3. Install Node.js dependencies
4. Fix package.json naming issues
5. Generate debug keystore for signing
6. Build release APK using Gradle
7. Copy APK to output directory

## Output
- **APK Location**: `./output/local-ai-assistant.apk`
- **Build Type**: Release APK with debug signing
- **Target**: Android API 34

## Model Configuration
The app is configured to use:
- **LLM Model**: `qwen2:0.6b` (as requested)
- **Embedding Model**: `nomic-embed-text`

## Installation Instructions
1. Enable Developer Options on your Android device
2. Enable USB Debugging
3. Connect device via USB
4. Install using: `adb install output/local-ai-assistant.apk`

## Ollama Setup Required
Before using the app, ensure Ollama is running with required models:
```bash
ollama pull qwen2:0.6b
ollama pull nomic-embed-text
```

## Troubleshooting

### Common Issues
1. **Build fails**: Check available disk space and internet connection
2. **Permission errors**: Ensure Podman has proper permissions
3. **APK won't install**: Check Android device settings and USB debugging

### Container Debugging
```bash
# Run container interactively for debugging
podman run -it --rm -v "$(pwd):/app" ubuntu:22.04 /bin/bash
```

## Security Notes
- Uses debug keystore for signing (suitable for development)
- For production, replace with proper signing configuration
- Container runs with necessary permissions for Android build

## Performance
- **Build Time**: ~15-30 minutes (depending on system)
- **Container Size**: ~4-6GB
- **APK Size**: ~50-100MB (estimated)
